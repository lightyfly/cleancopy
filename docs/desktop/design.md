# CleanCopy 用户行为流程与页面设计稿 v0.1

> 一句话：复制 Markdown 后，按 ⌘⇧V（Windows/Linux：Ctrl+Shift+V）立即按目标 App 规则智能粘贴；按独立的 ⌘⌥V（Windows/Linux：Ctrl+Alt+V）直接打开完整粘贴菜单，不先粘贴。普通 ⌘V / Ctrl+V 不受影响。
>
> 本稿定义产品行为契约，不是运行验收报告。当前原生桌面适配范围为 Linux X11；macOS / Windows 的快捷键、权限与界面描述是目标设计，不表示已完成原生实现或验收。下文时延数值为目标，不是实测结果。

## 0. 关键取舍：“右键菜单”如何落地
| 方案 | macOS | Windows | 结论 |
|---|---|---|---|
| 注入任意 App 的系统右键菜单 | 不可行（无公开 API；Services 菜单只对选中文本生效，且藏在二级菜单） | 不可行（只能扩展资源管理器的 shell 菜单，管不到 Word/记事本） | **不做** |
| **全局快捷键 + 跟随光标的浮动菜单** | 可行（需“辅助功能”权限来模拟粘贴和读取光标位置） | 可行（RegisterHotKey + SendInput） | **主方案**，即本产品的“右键菜单” |
| 菜单栏 / 托盘图标 | NSStatusItem | 系统托盘 | **辅助入口**：开关、撤销、设置 |
| 静默模式：智能粘贴直接按目标 App 规则执行，不弹完整菜单 | 可选 | 可选 | 设置项，默认开；独立完整菜单快捷键不受此项影响 |
| 接管 ⌘V | 技术上可行，但影响全系统粘贴，风险高 | 同左 | 不做（v1） |
| Windows 资源管理器 shell 扩展 | — | 只对文件有效，跟本场景关系不大 | 暂不做 |

光标位置：优先取文本插入点（macOS AX `kAXBoundsForRange`、Windows UIA/`GetGUIThreadInfo` 的 caret）；拿不到就用鼠标位置；全都拿不到就放在屏幕中央。

## 1. 用户流程
**1.1 首次启动与权限**
1. 首次使用引导说明两个独立入口：①复制文本后按「智能粘贴」快捷键，立即按目标 App 规则处理；②按「完整粘贴菜单」快捷键或从托盘打开菜单，先选择再粘贴。目标欢迎卡片可分 3 步并允许跳过：快捷键演示、授予权限、选择默认中文序号风格；不将该卡片描述为当前已交付的原生流程。
2. macOS 申请“辅助功能”权限，并给出按钮直接打开对应的系统设置页面；应用在后台轮询，授权成功后卡片自动打勾。Windows 不需要额外权限。
3. 完成后只在菜单栏/托盘留一个图标，不显示 Dock 图标。

**1.2 日常智能粘贴（识别成功）**：复制 Markdown → 回到 Word 按 ⌘⇧V（Ctrl+Shift+V）→ 静默模式默认开启，立即按 Word 富文本规则粘贴，不先弹完整菜单，也不等待 400ms 判断第二次按键。
- 关闭静默模式后，同一智能粘贴快捷键立即打开完整菜单，选择后才粘贴。
- 独立的 ⌘⌥V（Ctrl+Alt+V）始终直接打开完整的「粘贴原文 / 粘贴格式化文本 / 撤销上次转换」菜单，与静默模式无关，不先触发一次粘贴。连续按两次智能粘贴不再是打开完整菜单或执行默认项的手势。
- 暂停、菜单已打开、剪贴板恢复尚未完成时，两种快捷键都受相同的安全门控；「立即」表示无双击等待，不承诺零耗时或绕过安全检查。
- 识别依据：前台 App 的 bundle id / exe 名 / X11 WM_CLASS，与设置中的「App→格式」映射表匹配。

**1.3 未匹配 App → 兜底策略**：静默智能粘贴时，前台 App 不在映射表且「其他 App」为“弹出格式菜单”，显示「未识别目标」并打开二级格式菜单（见 floating-menu.png）。用户可用数字键或方向键选择启用的格式；勾选「记住此 App 的选择」后，按稳定 App 标识而非显示名称写入映射表。若兜底为固定格式，则直接按该格式粘贴。独立完整菜单快捷键仍打开完整菜单。

**1.4 粘贴原文**：在菜单中按 1，粘贴剪贴板原内容，不做任何转换。

**1.5 撤销**：先在目标 App 内按 ⌘Z 撤销刚才的粘贴；再从菜单/托盘点「撤销上次转换」，会重新粘贴原文（先 ⌘Z 再粘原文）。粘贴完成后剪贴板会恢复成用户原来复制的内容，不会被转换结果污染。

## 2. 界面规格
统一规范：浅色，主色 #5B5BD6，正文 13px，使用 SF Pro / Segoe UI + 苹方 / 微软雅黑。圆角规格：菜单 12px，控件 6px。间距按 4/8 栅格，菜单行高 30px。Windows 上使用 Mica 背景和 Segoe 字体，快捷键显示为 Ctrl/Shift。

**2.1 浮动粘贴菜单**（floating-menu.png）
- 宽 320px，从上到下依次是：剪贴板摘要（类型 · 字数）与识别状态标签；粘贴原文 / 粘贴格式化文本 › / 撤销上次转换；底部一行操作提示。
- 二级菜单在右侧展开，右侧放不下时向左展开。菜单项及顺序由设置页决定。
- 操作：↑↓ 选择，↵ 确认，→ 展开二级菜单，esc 或点击菜单外部关闭。菜单不抢目标窗口焦点（macOS 使用 nonactivating panel）。

**2.2 菜单栏 / 托盘**（tray.png）：总开关、最近 2 次粘贴记录、「唤出粘贴菜单」（快捷键提示使用当前配置的完整菜单快捷键）、撤销、暂停 1 小时、设置…、退出。该菜单入口与独立完整菜单快捷键语义相同：直接打开完整菜单，不先执行智能粘贴。

**2.3 单页设置**（settings.png，1120×720，左右分栏）
- 左栏（440px）：①App→格式映射表（可添加 App、可下拉选择格式，最后一行「其他 App」作为兜底，可选“弹出格式菜单”或某个固定格式）；②中文序号风格（分段控件）；③二级菜单项（勾选决定是否显示，拖动排序，数字键自动编号）；④两个独立的快捷键录制控件：「智能粘贴」和「完整粘贴菜单」。
- 右栏是实时预览：左边是可编辑的示例 Markdown，右边是转换效果。顶部分段控件可切换纯文本 / Word / Markdown；在左栏选中某个 App 时，预览自动切换到该 App 对应的格式。
- 没有“保存”按钮，改动即时保存；保存失败必须提示并允许重试，不把写入失败当作成功。底部提供「恢复默认」，同时恢复两个默认快捷键。
- 两个快捷键分别存为 `hotkey`（智能粘贴）和 `full_menu_hotkey`（完整菜单），独立持久化并按字段合并。旧配置缺少 `full_menu_hotkey` 时补上平台默认值，不覆盖已定制的 `hotkey`。macOS 的默认存储值分别为 `Super+Shift+V` 和 `Super+Alt+V`，显示为 Cmd+Shift+V 和 Cmd+Option+V；其他平台分别为 `Ctrl+Shift+V` 和 `Ctrl+Alt+V`。
- 点击某一录制控件后，仅更新该快捷键；Esc 取消。两个动作不能使用相同组合键，重复时保留原值并提示。原生注册冲突须报告，不能仅更改显示标签却假装快捷键已生效。托盘提示和首次使用说明应与当前配置的两个动作一致。

## 3. 转换规则（默认）
- 纯文本 · 中文序号：H1 作为文档标题，不加序号；H2→一、 H3→（一） H4→1. H5→（1）。列表不参与标题编号，按自己的阶梯编号：1. →（1）→ ①；最近的标题已用 1. 这一级时从（1）开始；同一套编号不会出现在两个层级上（详见 docs/design.md §7.1）。去掉 `** _ # >` 等 Markdown 符号。表格转成按制表符对齐的文本，代码块原样保留并缩进 4 格。
- Word 富文本：写入 HTML + RTF 两种剪贴板格式。H1/H2/H3 分别对应 Word 内置样式「标题 1/2/3」（WPS 也能识别）。加粗、斜体、列表、表格、行内代码、代码块（等宽字体 + 浅灰底）都保留。
- 可选的序号风格：一、（一）1.（1） ／ 一、1. (1) ／ 1. 1.1 1.1.1。

## 4. 状态与边界
| 情况 | 行为 |
|---|---|
| 非 Markdown 内容（检测不到标题/列表/强调等语法） | 菜单显示「普通文本」，默认项改为粘贴原文，格式化选项置灰但仍可点 |
| 剪贴板里已经是富文本（HTML） | 优先使用复制源自带的 Markdown；没有的话把 HTML 转成 Markdown 再转换 |
| 超大文本（>200KB） | 转换在后台线程执行，菜单项显示进度；超过 2 秒可取消；超过 5MB 只提供粘贴原文 |
| 图片 / 文件 | 菜单显示「图片，不支持转换」，只保留粘贴原文 |
| 混合内容（文字 + 图片） | 文字照常转换，图片用占位符标出位置并在菜单里提示 |
| 识别失败 | 走 1.3 的二级菜单 |
| 权限被拒（macOS） | 仍然弹出菜单，选择后把结果写入剪贴板，并提示“已复制，请按 ⌘V”；托盘图标显示黄点，并提供重新授权入口 |
| 快捷键冲突 | 录制快捷键时检测冲突并提示，给出备选快捷键 |
| 安全输入（密码框） | 不弹菜单，在托盘中提示原因 |

## 5. 验收标准
1. 从 ChatGPT / Gemini 网页版和桌面版点“复制”后，粘贴到 Word 和 WPS：标题样式显示为「标题 1/2」，表格可以编辑，加粗保留。
2. 粘贴到记事本 / TextEdit：没有任何 Markdown 符号，序号符合当前选择的风格，3 层以上嵌套也正确。
3. 从按下快捷键到菜单出现 ≤100ms；1 万字转换并粘贴完成 ≤300ms（M1 / i5 级别机器）。
4. 静默模式下，映射表外且兜底为弹出菜单的 App 打开二级格式菜单；固定格式兜底直接粘贴。勾选“记住”后，下次按稳定 App 标识匹配。独立完整菜单快捷键不受上述分流影响。
5. 撤销能恢复原文；每次粘贴完成后，剪贴板内容与用户原先复制的一致。
6. 修改设置后，预览在 50ms 内刷新；关闭设置再打开，配置不丢失。
7. 拒绝权限后不崩溃，降级为“写入剪贴板 + 提示”，并能引导用户重新授权。
8. 截图对照：间距、对齐、配色与本稿一致；macOS 和 Windows 分别使用各自平台的快捷键符号。

## 6. 已定快捷键契约
静默模式默认开启。智能粘贴立即按规则执行，不保留 400ms 双击窗口；关闭静默模式则立即打开完整菜单。完整菜单使用独立快捷键，始终先打开菜单再由用户选择。两个快捷键分别录制、保存、恢复默认；普通系统粘贴不变。这些条目是契约要求，不替代原生运行证据。
