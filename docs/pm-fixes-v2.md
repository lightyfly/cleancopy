## Evidence and known issues

- [Prior workspace execution](evidence/pm-prior-workspace.log) records the named PM regressions available at that stage. It predates the last baseline additions; it is not the final count.
- [Prior native execution](evidence/pm-prior-native.log) records secondary **29.91 ms**, 10k paste **48.27 ms**, and large-source Full **2226.19 ms** (rounded **2226 ms**). Its S-01 PASS text incorrectly says Escape: actual code clicked 取消. This historical log is retained unmodified; the source label is now accurate.
- **Known performance reliability issue:** [earlier native attempt](evidence/pm-prior-secondary-failure.log) measured secondary **164.96 ms** and actually failed the ≤100 ms assertion. Later successful attempts do not erase this failure or establish a percentile guarantee.
- **Known large-source Full-open slowness:** the **2226.19 ms** sample is time to mapped and painted Full for 180,000 repeated Markdown blocks. Background *conversion* does not prevent synchronous clipboard reading/source preparation before menu display. Full timings are reported, not ≤100 ms gated; a passing matrix does not mean this slowness is fixed.
- Native peers are independent Linux X11 fixtures, not installed gedit/Word/WPS. macOS/Windows runtime, real secure-input fields, real tray-host integration, and real target-app formatting remain unverified.
